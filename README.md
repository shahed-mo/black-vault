#  BLACK VAULT

> **Every case has a secret. Every clue tells a story.**

BLACK VAULT is a detective investigation web application built with **React + TypeScript**.
Players can investigate mysterious cases, examine suspects and evidence, and try to identify the real culprit.

## Features

* Investigate different cases
*  Browse active case files
*  Examine suspects and evidence
*  Accuse a suspect
*  Get instant results after solving a case
*  Keep track of solved mysteries
*  Save solved cases using Local Storage
*  Responsive design
*  Dark detective-inspired interface

## 🛠️ Technologies

* React
* TypeScript
* React Router
* Tailwind CSS
* Local Storage
* Vite

##  Main Pages

* **Home** — Detective headquarters
* **Active Cases** — Available investigations
* **Case Files** — Investigate a selected case
* **Case Result** — View the result of your accusation
* **Solved Mysteries** — View successfully solved cases

## Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

##  Project Goal

The goal of BLACK VAULT is to create an interactive detective experience while practicing modern **React, TypeScript, routing, state management, and browser storage**.
